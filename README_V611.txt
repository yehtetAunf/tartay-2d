Admin now has a separate Today Round Result panel.
1. Choose round (05:00 PM - 12:00 AM)
2. Enter SET and VALUE
3. 2D auto-calculates: SET last digit + VALUE last digit before decimal
   Example SET 1367.42, VALUE 56789.81 => 29
4. Publish Round Result saves SET, VALUE and 2D through existing /api/admin/result.
